Introduction & Domain

What is a Pharmacy Supply Chain?

Slide 2 / 20
A pharmacy supply chain is the step-by-step process of how medicines travel safely from pharmaceutical manufacturers to hospital pharmacies and patients.
🏭 1. Manufacturer
Produces pharmaceutical drugs in discrete batches with fixed manufacturing and expiry dates.
🚚 2. Distributor / Supplier
Transports medicine boxes to hospitals while maintaining safe temperature standards.
🏥 3. Hospital Pharmacy
Stores stock safely, checks expiry, and dispenses the right medicine batch to patients.

Why is Proper Tracking Important?

  • Patient Safety: Patients must never receive an expired, compromised, or counterfeit drug.
  • Drug Potency: Temperature-sensitive medicines like Insulin lose strength if stored in the wrong temperature.
  • Preventing Losses: Using medicines in the correct order prevents medicines from expiring on pharmacy shelves.
Problem Statement

Real-World Pharmacy Inefficiencies

Slide 3 / 20

Hospital pharmacies face 5 major practical challenges that cause medical and financial losses:

⏳ 1. High Medicine Expiry Wastage
Medicines often sit unnoticed in storage racks and expire before staff realizes they need to be used.
❌ 2. Random Dispensing Order
Staff naturally pick the newest boxes in front, leaving older batches behind to expire unnoticed.
🌡️ 3. Unmonitored Cold-Chain Storage
Medicines like Insulin or Vaccines spoil if refrigerators get too warm, but temperature checks are rarely automated.
🛡️ 4. Counterfeit Medicine Risks
Unverified or fake medicine batches can enter the hospital supply chain without a quick verification tool.
📝 5. Manual Inventory Errors
Paper-based stock logs lead to human counting mistakes, stock-outs during emergencies, and missing batches.

Database Design

Normalized MySQL 3NF Database Structure

Slide 11 / 20
The database is normalized to Third Normal Form (3NF). This avoids repeating data and guarantees that every table has a Primary Key and clean Foreign Keys.
medicines Table
Columns: id (PK), name (UNIQUE), generic_name, category, dosage, min_temperature, max_temperature, created_at.
Purpose: Stores the official drug catalog and storage rules.
suppliers Table
Columns: id (PK), supplier_name (UNIQUE), contact_person, phone, email, address, created_at.
Purpose: Stores authorized distributor credentials.
batches Table
Columns: id (PK), batch_number (UNIQUE), medicine_id (FK), supplier_id (FK), manufacturer, manufacturing_date, expiry_date, quantity, storage_requirement, verification_status.
Purpose: Physical inventory ledger used for FEFO sorting.
temperature_logs Table
Columns: id (PK), batch_id (FK), recorded_temperature, recorded_at, compliance_status, notes.
Purpose: Stores cold-chain temperature readings.
Simple Relationships: 1 Medicine ➔ has many Batches | 1 Supplier ➔ provides many Batches | 1 Batch ➔ has many Temperature Logs

⚖️ Easy FEFO Concept Explained
FEFO Rule: "The batch that expires first must be used first."
Batch A: Expires 10-October-2026 (Qty: 20)
Selected 1st (Earliest Expiry)
Batch B: Expires 15-December-2026 (Qty: 40)
Selected 2nd (Expires Later)

When dispensing 10 units of Paracetamol, our system automatically deducts 10 from Batch A and leaves Batch B untouched.

Database Operations

Database CRUD Operations via JPA

Slide 16 / 20

The application interacts with MySQL using safe, automated CRUD operations via Spring Data JPA:

CRUD Action Pharmacy Operation Java / JPA Execution Database Effect
C — Create Register new medicine or add batch medicineRepository.save(medicine) INSERT INTO medicines ...
R — Read Query batches in FEFO order findAvailableBatchesForFefo() SELECT ... ORDER BY expiry_date ASC
U — Update Deduct stock; change verification status batch.setQuantity(newQty) UPDATE batches SET quantity = ?
D — Delete Remove old or canceled records medicineRepository.deleteById(id) DELETE FROM medicines WHERE id = ?
SQL Injection Protection: All database queries use Spring Data JPA parameterized inputs. No raw SQL strings are concatenated, protecting the hospital pharmacy from SQL injection attacks.
